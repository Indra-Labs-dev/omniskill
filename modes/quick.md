# Mode QUICK

For one-step, low-risk tasks: a factual answer, a small edit, a single command.

- Act directly. No written plan, no task list.
- One acceptance criterion is usually enough; state it to yourself.
- Verify in proportion: re-read the edited line, run the one command, check the one source.
- Report in one line: `STATUS: VERIFIED — <what you checked and saw>` or `STATUS: UNVERIFIED — <why not checked>`.

Escalate to PRO as soon as the task shows several dependent steps, more than one file to change, or a deliverable that needs testing.
